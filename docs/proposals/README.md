# Proposals

Changes to the interface contract, conventions, or the set of modules start as a proposal here.

1. Create `docs/proposals/NNNN-short-title.md` (next free number).
2. Include: problem, proposed change, affected modules, migration or upgrade impact, alternatives considered.
3. Open a pull request. Discussion happens on the PR; merge means accepted.
4. Once implemented, set `Status: implemented` at the top of the file and link the PRs.

Status values: `draft`, `accepted`, `implemented`, `rejected`.
